# Cotton Grade Image Scraper — Design Spec
**Date:** 2026-05-04  
**Status:** Approved

---

## Goal

Source 3–5 real cotton sample photos per grade (16 grades = ~48–80 images), store in Supabase Storage, and wire them into three app surfaces: Visual ID Drill, Grading Screen, and Flashcards.

---

## Scraping Pipeline

Script: `scripts/cotton_image_scraper.py`

### Phase 1 — Firecrawl

Crawl the following sources per grade using Firecrawl's image extraction mode:

- USDA AMS cotton standards pages (`ams.usda.gov`)
- Texas A&M AgriLife Extension cotton publications
- Cotton Incorporated resource library
- TAMU cotton classing guides

Filter criteria:
- Minimum resolution: 400×400px
- Filename or alt-text contains grade-relevant keywords (grade code, quality rank, "cotton", "fiber", "sample")

Target: 3–5 images per grade code.

### Phase 2 — GPT Image 2 Gap Fill

Any grade with fewer than 3 images after Phase 1 triggers GPT Image 2 generation.

Prompt template:
```
USDA upland cotton fiber sample, grade {name} ({code}), {description}.
White background, studio lighting, top-down view, realistic fiber texture,
photo-realistic, no text overlays.
```

Generate enough images to reach 3 per grade.

### Phase 3 — Upload to Supabase Storage

- Bucket: `cotton-grade-images` (public)
- Path: `cotton-grade-images/{grade_code}/{index:03d}.jpg`
  - e.g. `cotton-grade-images/31/001.jpg`
- Script outputs `assets/data/cotton-grade-image-urls.json` — committed to repo

## Storage + Data Model

### Supabase Storage

| Field | Value |
|-------|-------|
| Bucket | `cotton-grade-images` |
| Access | Public |
| Path pattern | `{grade_code}/{index:03d}.jpg` |
| Expected total | 48–80 images |

### `assets/data/cotton-grade-image-urls.json`

Generated by scraper, committed to repo, imported statically at runtime.

```json
{
  "21": ["https://<project>.supabase.co/storage/v1/object/public/cotton-grade-images/21/001.jpg"],
  "31": ["...", "..."],
  ...
}
```

### `lib/data/cotton-grades.ts`

Add optional field to `CottonGrade` interface:

```ts
imageUrls?: string[];
```

At app startup, merge JSON into `COTTON_GRADES` array. No DB query — static import.

## App Changes

### A. Visual ID Drill — new screen

**File:** `app/practice/cotton/visual-id.tsx`

- Shows cotton sample photo (random from `imageUrls[]` for active grade)
- Student picks grade from 4-choice grid (correct + 3 distractors drawn from adjacent grades)
- Scored with existing `scoreGuess()` — 20/10/0 pts for exact/adjacent/wrong
- Results screen shows per-grade breakdown
- `lib/store/history.ts` — add `'cotton-visual-id'` to `PracticeType` union

### B. Grading Screen Enrichment

**File:** `app/practice/cotton/grading.tsx`

- Each grade card gets a horizontal `FlatList` image carousel (swipeable)
- 3–5 photos per grade displayed below description
- Falls back gracefully to text-only if `imageUrls` empty

### C. Flashcard Augmentation

**File:** `app/practice/cotton/flashcards.tsx`

- Card front: random sample photo from `imageUrls[]`
- Card back: grade name, code, series, clues (existing)
- Falls back to text-only front if no images loaded

### D. Hub Update

**File:** `app/practice/cotton/index.tsx`

- Add "Visual ID" button in the study mode grid alongside Study/Flashcards/Quiz

## Implementation Order

1. Create Supabase Storage bucket `cotton-grade-images`
2. Run `scripts/cotton_image_scraper.py` (requires `FIRECRAWL_API_KEY` in `.env`)
3. Verify `assets/data/cotton-grade-image-urls.json` output
4. Add `imageUrls?: string[]` to `CottonGrade` interface + merge logic
5. Build `visual-id.tsx` screen
6. Enrich `grading.tsx` with image carousel
7. Augment `flashcards.tsx` with photo front
8. Update `index.tsx` hub with Visual ID button
9. Add `'cotton-visual-id'` to `PracticeType` in `history.ts`

---

## Error Handling

- If `imageUrls` is empty/undefined: all three surfaces render text-only (no crash)
- Scraper logs grades where Phase 1 yields 0 results — Phase 2 fires automatically
- Image load failures in app: show grade color swatch placeholder

## Prerequisites

- `FIRECRAWL_API_KEY` added to `.env`

- Supabase Storage bucket `cotton-grade-images` created (public)
- Python deps: `firecrawl-py`, `requests`, `Pillow`, `supabase`
