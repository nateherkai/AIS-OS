## Current Brand System

### Voice

**Archetype:** Authoritative Coach + Competitive Motivator. Expert, direct, metric-focused. Never condescending.

**By audience:**
- **Students:** metrics-driven, strategy-focused. Example: "Your last 3 tests dropped. Focus on parasite ID first."
- **Teachers:** professional peer, outcome-focused. Example: "Your students get 24/7 AI feedback. You get readiness dashboards."
- **Parents:** investment confidence, proof-based. Example: "FFA-aligned curriculum. Track competition readiness."

**Use:** CDE, placing(s), score, mastery, judge perspective, evaluation criteria, "24/7 AI feedback," "AI-guided practice," "progress dashboard"

**Avoid:** "fun," "easy," "quick," "gamified," "unlock," "student journey," "learning experience," "skill-building," superlatives without proof

### Color Palette

| Color | Hex | Use |
|---|---|---|
| Navy | `#001F4D` | Authority / primary UI |
| Gold | `#D4A574` | Achievement / progress accents |
| White | `#FFFFFF` | Text on dark |
| Dark Gray | `#2B2B2B` | Backgrounds / glass surfaces |

**Dark glass aesthetic** — all screens use dark glass. Import `Theme` and `GlassEffect` from `constants/theme.ts`. No light backgrounds.

### Typography

Bold serif or sans-serif headings. 16px body. Large bold navy metric numbers (32–48px) with gold accents. Strong weight hierarchy — bold is BOLD.
