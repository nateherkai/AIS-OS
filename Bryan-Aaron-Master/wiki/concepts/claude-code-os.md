# Claude Code OS (Operating System)

A visual intelligence dashboard concept built on top of Claude Code that unifies all AI tools, memory systems, skills, and costs into one centralized view. Coined and demonstrated by Jack Roberts.

## The Problem It Solves

Most Claude Code users have disconnected pockets of intelligence: separate chat interfaces, scattered memory systems, unknown spend, unmeasured skill ROI, and no macro view of how they're actually using AI. The CC-OS makes all of this visible and actionable.

## Six Pillars

The CC-OS is organized around six core components of any AI operating system:

1. **Models** — which LLMs you use (Claude, ChatGPT, Gemini, DeepSeek, Codex, etc.) and what tier/plan
2. **Plans** — API vs. subscription billing, tier optimization
3. **Memory** — local Obsidian, Pinecone, Supabase, or other storage; detects stale memories
4. **Skills** — skills library with last-used dates, time-saving estimates, kill/keep decisions
5. **Knowledge** — connected knowledge systems (wikis, RAG, databases) with visual graph
6. **Connections** — everything plugged into the OS; what's live, what's misconfigured

See: [[../concepts/six-pillars-os|Six Pillars OS]]

## What the Dashboard Surfaces

- Net ROI (time/money saved by skills minus AI spend)
- Token limits and usage per model
- API cost equivalent for subscription-based usage
- Skill performance (last used, estimated value)
- Daily Dreaming Engine recommendations (four high-leverage items each morning)
- Knowledge graph visual (Obsidian + Pinecone + Supabase unified)
- Sessions per day, workflow patterns

## How It's Built

A static HTML dashboard driven by data the Dreaming Engine writes each night. The onboarding wizard auto-detects models and memory systems on the local computer. Users set hourly rate to unlock ROI calculations.
