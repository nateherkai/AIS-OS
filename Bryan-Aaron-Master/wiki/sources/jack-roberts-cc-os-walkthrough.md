# Jack Roberts — Claude Code OS Walkthrough

YouTube video where Jack Roberts (former tech startup founder) demonstrates his Claude Code Operating System dashboard — a visual intelligence layer that unifies models, plans, memory, skills, knowledge, and connections into one interface. Includes an original "Dreaming Engine" implementation inspired by Anthropic's research preview of overnight agent memory.

## Core Claims

- Most Claude Code users are flying blind — they don't know what they're spending, what skills are being used, whether memory is stale, or what's connected.
- The CC-OS dashboard solves this by making all of that visible in one place.
- Six pillars define a complete AI operating system: Models, Plans, Memory, Skills, Knowledge, Connections.
- The Dreaming Engine (Jack's term) runs nightly analysis across eight dimensions, generates four high-leverage improvement recommendations each morning.
- Onboarding clients with this dashboard makes ROI visible — time saved, cost saved, net return.
- Anthropic shipped a research preview of "Dreaming" but Jack built his own, expanded beyond Claude to all AI tools on the computer.
- The "visualization layer of AI" is the next major trend — as models get better at creating, the question becomes "how do I see the thing?"

## What the Dashboard Shows

- Models in use + API vs subscription tier
- Token limits and usage per model (Claude Pro Max, ChatGPT, OpenRouter, etc.)
- Net ROI = time/money saved by skills minus AI spend
- Subscriptions dashboard with API cost equivalents
- Skills list: last used, time saved estimate
- Connected knowledge systems (Obsidian, Pinecone, Supabase)
- Daily Dreaming Engine recommendations with action/dismiss UI
- Sessions per day, workflow patterns
