# Ag Coach Pro: Brand & Design Style Guide

Use the following specifications for all sales, marketing, and development assets to ensure brand consistency.

---

## 🎨 Core Color Palette (Hex Codes)
| Element | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary Accent** | `#F2A900` | Ag Gold / Branding / Main CTAs |
| **Secondary Accent** | `#00f2ff` | Cyber Blue / Progress / Highlights |
| **Background** | `#000000` | Pure Black / Base Layer |
| **Surface** | `#0a0a0a` | Deep Dark / Cards & Sections |
| **Success** | `#4CAF50` | Achievements / Positive Status |
| **Error** | `#F44336` | Alerts / Negative Status |
| **Warning** | `#FF9800` | Notifications / Neutral Status |

---

## ✨ Design Aesthetic: "Cyber-Agronomy"
*   **Theme**: Premium Dark Mode.
*   **Visual Style**: Modern, sleek, and data-focused.
*   **Glassmorphism**: Use translucent surfaces with subtle borders (`rgba(255,255,255,0.1)`) and background blurs.
*   **Typography**: **Inter** (San-Serif). Bold, high-weight headings with clean, breathable body text.
*   **Icons**: Use high-contrast icons. Specifically, **Bright White & Black Checkered Flags** (racing style) for all goals and finish-line milestones.

---

## 🚀 Key Brand Value
*"Bridging the gap between traditional agricultural education and modern competitive standards through data-driven Advisor Intelligence."*

---

## 📸 Imagery Guidelines
*   **Livestock**: High-resolution, photorealistic imagery for anatomy and identification.
*   **Infographics**: Clean, high-resolution data visualizations with vibrant accent colors.
*   **UI Elements**: Rounded corners (20px - 28px) and high-contrast text for accessibility on large screens.
