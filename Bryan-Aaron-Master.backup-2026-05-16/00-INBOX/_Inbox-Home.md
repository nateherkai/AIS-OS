# 00-INBOX — Capture First, Sort Later

> Default landing zone for everything. If you don't know where it goes, it goes here.
> Process this folder **weekly** — every note should leave here and go to its proper folder.

---

## How to Use This Folder

**Capture first.** When an idea, task, link, quote, or thought hits you — drop it here. Don't slow down to file it perfectly.

**Process weekly.** Every Sunday (or whenever you have 15 minutes), review everything in here and either:
- Move it to the right folder
- Turn it into an actionable note
- Delete it if it's not worth keeping

**Nothing lives here permanently.** If a note has been sitting here for 2+ weeks, it either matters and needs a home, or it doesn't matter and needs to go.

---

## Quick Capture Template

When you drop a note here, use this format so future-you knows what it was:

```
# [Topic or Title]

Date: YYYY-MM-DD
Type: Idea / Task / Reference / Question / Other

[Your note here]

→ Route to: [where this should go eventually]
```

---

## Weekly Processing Checklist

- [ ] Review all notes in 00-INBOX
- [ ] Move each to correct folder (01–07)
- [ ] Convert tasks to action items
- [ ] Delete anything that doesn't matter
- [ ] Inbox = empty (or close to it)
