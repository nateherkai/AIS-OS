# Job Search

Automate Yuan's search for a remote/startup **Software or AI Engineering** role end to end. Shared context lives at the repo root (`context/`, `references/voice.md`, `connections.md`); this folder holds the working files.

## Goal
Surface 10+ quality roles/week, auto-tailor CV + cover letter per role, build recruiter/network reach, and convert a shortlist of 20 target startups into warm intros and interviews. Target comp: $150K+ AUD plus super.

## Files
- **`applications.md`** — the pipeline tracker. One row per opportunity, lead → offer.
- **`tasks.md`** — what to do next. Simple markdown checklist.
- **`notes/`** — recruiter-call and interview notes, one file per conversation.
- *(coming)* `cv/` and `cover-letters/` — tailored `.md` variants per application, converted to PDF only at send time.

## The pipeline (target workflow)
1. **Discover** — pull roles from Seek, LinkedIn, Wellfound, YC Work at a Startup, HN Who's Hiring → filter to 10+ quality matches/week → log as leads in `applications.md`.
2. **Tailor** — for each chosen role, generate a tailored CV + cover letter from the master CV, in Yuan's voice.
3. **Apply + track** — submit, set status, capture next action.
4. **Network** — find + connect with key recruiters/people on LinkedIn + X; follow up warmly.
5. **Stay current** — short weekly industry-news routine.

Most of this is manual today. Automating it is Priority 1 — chip away one piece per `/level-up`.
