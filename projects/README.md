# Projects

One workspace per initiative. AIOS-level context (identity, voice, priorities, connections) lives at the repo root and is shared across every project here — don't duplicate it.

## Active
- **`job-search/`** — automate Yuan's search for a remote/startup Software or AI Engineering role. First and current focus.

## Adding a project
Create `projects/<name>/` with its own `README.md`. Pull shared context from `../../context/` and `../../references/`. Keep the project's working files (trackers, notes, drafts) inside its own folder.
