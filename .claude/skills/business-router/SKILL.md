# Business Router

Bryan runs 5 business avenues. Each has its own context file under `context/businesses/`. Before answering a business-specific task, identify which avenue applies and load that file.

## Inputs

- A task or question from Bryan that mentions or implies a business.

## Logic

1. **Check explicit signal:** does the task name a business directly?
   - "Ag Coach Pro" / "ACP" / "FFA" / "Texas FFA" / "Lone Star Elite" / "Blue & Gold" / "Greenhand" → `ag-coach-pro.md`
   - "AFL" / "Aaron Family Livestock" / livestock-show-prep mention → `afl.md`
   - "Livestock Solutions" / "hauling" / "show prep service" → `afl-livestock-solutions.md`
   - "Detailing" / "detail" / "wash" → `afl-detailing.md`
   - "Ranch Dad" / "Ranch Dad Strength" / "RDS" / fitness/strength content → `ranch-dad-strength.md`

2. **Check implicit signal:** if no explicit mention, check:
   - Customer name → cross-ref to known ACP trial DB (Supabase `nkoyotdafqllgbpuklva`).
   - Channel: support@agcoachpro.com email → ACP. Facebook page name → match.
   - Domain: agcoachpro.com → ACP.

3. **If still ambiguous:** ask Bryan which business in one sentence, do not guess.

4. **Load the file:** `Read` the chosen `context/businesses/*.md` and use its voice + facts to answer.

5. **If routed to a STUB file:** warn Bryan the file is a stub and ask if he wants to fill it now or proceed with limited context.

## Output

A routed answer that cites the loaded business file. Format:

```
Routed to: <business>
Context loaded: context/businesses/<file>.md
Answer: <answer>
```

## Verification

- Run `/route "what's my pipeline look like"` → should route to Ag Coach Pro (only business with pipeline data).
- Run `/route "schedule the trailer wash"` → routes to AFL Detailing.
- Run `/route "post about leg day"` → routes to Ranch Dad Strength.
- Ambiguous case ("send a follow-up") → should ask which business.
